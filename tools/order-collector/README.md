# 구매내역 수집기

온라인으로 산 옷을 하나씩 등록하는 게 번거로워서, **내 PC의 크롬을 그대로 띄워** 로그인해 둔
쇼핑몰의 구매내역에서 상품 목록만 긁어 오는 로컬 도구다. 이미지 추출·등록은 RealCloset이 한다.

```
① 이 스크립트가 크롬을 띄운다 → 내가 직접 로그인 → 구매내역에서 상품 목록만 수집
② 결과(JSON)를 RealCloset [아이템 추가 → URL]에 붙여넣기 → 후보 목록에서 고르기
③ 고른 것만 알아서 이미지 추출 + 이름·색·카테고리·구매처·계절까지 등록
```

## 설치와 실행

```bash
cd tools/order-collector
npm i                        # 처음 한 번 (playwright)
npm run collect              # 플랫폼을 골라서 수집
npm run collect -- --all     # 등록된 플랫폼 전부
npm run collect -- --platform musinsa,29cm
npm run collect -- --keep-open   # 끝나도 브라우저를 닫지 않는다
```

수집이 끝나면 `orders.json`이 생기고, macOS에서는 클립보드에도 복사된다. 그대로 RealCloset의
`아이템 추가 → URL` 칸에 붙여넣으면 후보 목록이 뜬다. 상품 URL을 여러 줄로 붙여넣어도 된다.

## 로그인은 사람이 한다

아이디·비밀번호를 묻지도, 저장하지도, 전송하지도 않는다. 로그인은 열린 크롬 창에서 직접 하고,
그 세션만 전용 프로필(`~/.lookbox-collector/chrome`)에 남아 다음 실행에 재사용된다. 2단계 인증도
그 창에서 그대로 통과하면 된다.

## 지원 플랫폼

무신사 · 29CM · 지그재그 · 에이블리 · W컨셉 · KREAM · 네이버페이 주문내역 · 브랜디 ·
SSG닷컴 · 쿠팡 · 더현대닷컴 · 머스트잇 (`platforms.mjs`)

수집 로직은 셀렉터가 아니라 '상품 링크처럼 생긴 앵커'를 찾는 방식이라(`extract.mjs`) 목록
구조가 바뀌어도 잘 버틴다. 주소가 바뀌어 목록을 못 찾으면 **열린 창에서 직접 구매내역 페이지로
이동한 뒤 Enter**를 누르면 그 화면에서 그대로 가져온다. 목록에 없는 브랜드 자사몰도 이 방법으로 된다.

## 비용이 어디서 드는가

수집(①)은 페이지의 텍스트만 읽으므로 **AI 비용이 0원**이다. 스크린샷을 모델에 넣어 화면을
해석하는 방식(컴퓨터 조작 에이전트)은 세션당 $0.3~1.5가 들고 느려서 쓰지 않았다.

돈은 ③에서 든다. 아이템 40개 기준 실측:

| 항목 | 단가 | 40개 |
|---|---|---|
| 상품 이미지 가져오기 | 네트워크만 | $0 |
| 분류(이름·카테고리·색·계절·숨은 속성) | $0.0055/건 | $0.22 |
| 컷아웃 — 쇼핑몰 상품컷 | 로컬 처리 | $0 |
| 컷아웃 — 연출·모델컷 (30% 가정) | $0.07/건 | $0.84 |
| **합계** | | **약 $1.1** |

상품컷 비율이 높을수록 0에 수렴한다. 쇼핑몰 og:image는 대개 단색 배경 상품컷이라 대부분
로컬 컷아웃으로 끝난다.
