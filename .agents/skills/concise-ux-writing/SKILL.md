---
name: concise-ux-writing
description: UI 문구·버튼·모달·안내·오류 메시지를 작성하거나 수정할 때 마지막으로 길이, 중복, 줄바꿈, 조치 명확성을 검토한다. 일반 대화나 장문 문서에는 적용하지 않는다.
---

UI 문구 작업을 마무리할 때 별도 요청 없이 적용한다. 사용자는 불필요하게 긴 설명으로 레이아웃이 깨지거나 어색하게 줄바꿈되는 것을 싫어한다.

- 행동에 필요한 정보만 남긴다. 카테고리와 개수로 충분한 선택 오류에는 상품명을 붙이지 않는다. 예: `모자 2개 중 1개만 남겨 주세요`.
- 조치가 여러 개면 중립적인 제목 아래 각각 짧은 목록으로 나열한다. 실제로 부족한 카테고리만 안내한다. 제목에서 별도 조치를 요구하지 않는다.
- 모달은 질문과 설명의 간격을 좁히고 관련 설명은 하나의 문단으로 묶는다. 비용·결과 수처럼 결정에 필요한 정보는 생략하지 않는다.
- `다시 보지 않기`는 프로젝트의 공통 체크박스를 쓴다. 같은 의미의 다른 모달도 같은 형태로 맞춘다.
- 이미 보이는 안내를 반복하지 않는다. 유용한 팁이 없으면 보조 문구만 비우고 기존 공간과 탭 높이는 유지한다.
- 표시용 비율·회전은 정수로 줄이되 실제 편집 값의 정밀도는 유지한다.
- 아이콘은 실제 동작을 설명해야 한다. 요소 전체를 드래그할 수 있으면 별도 이동 핸들을 강요하지 않는다.
- 변경된 모든 상태를 PC와 좁은 모바일 폭에서 확인한다. 긴 문구를 nowrap이나 말줄임으로 덮지 말고 먼저 줄인다. 필요한 줄바꿈은 허용하고 키보드 포커스와 접근성 이름은 유지한다.

마지막에 제목·본문·버튼 사이의 반복, 동시 지시의 혼동, 불필요한 문단 간격, 동적 숫자 및 긴 입력에 따른 넘침을 검토하고 수정한다. 실제 화면 확인을 하지 못했다면 검토 완료로 단정하지 않는다.
