# AI 착장 개인화 토글

마이페이지 설정의 `내 얼굴·체형에 맞춰 보기`는 기본 off다. on 전환 시 프로필 사진·키·몸무게를 입력하는 시트를 열고, `다시 열지 않기`를 선택하면 `user_metadata.prefs.personalModelLookDontAsk`에 계정 단위로 저장한다. 사진·신체 정보가 없으면 저장할 수 없다(`frontend/src/proto/08-mypage.jsx`, `09-app.jsx`).

개인화 착장 생성은 프로필 사진과 키·몸무게를 `/api/live/coordinate/looks`에 전달한다. Image 1은 사용자 얼굴·머리·정체성만, Image 2는 무신사 AI 스냅의 포즈·표정·시선·조명·구도만 참조한다. 스냅 모델의 체형과 셀카 크롭 비율을 몸의 기준으로 삼지 않는다(`backend/app/main.py`, `_personal_look_body_note`, `_model_look_prompt_with_reference`).

## 체형 4단계 — 2026-10-04 적용

키 120~230cm·몸무게 30~220kg 유효 입력을 사용한다. 몸무게÷키(m)² 비율을 시각적 체형 선택에만 활용하고 건강 상태를 분류하지 않는다. 20 미만은 마른 편, 20~24 미만은 보통, 24~28 미만은 약간 풍성, 28 이상은 풍성한 체형이다. 허리·몸통·팔·허벅지의 볼륨과 옷의 떨어짐을 적당히 바꾸고 극단적인 마름·체격 확대·근육 생성은 금지한다. 실측 체형 복원이나 정확한 사이즈 예측이 아니다. 입력 누락·비정상 수치는 숫자를 추측하지 않고 자연스러운 보통 체형을 사용한다.

개인화 off는 기존 레퍼런스 체형과 보정 지시를 유지한다. on/off 모두 남녀별 스냅을 섞어 순환하고 약80% 전신 크기·위아래 여백·기존 AI 생성 표시를 유지한다. 같은 코디의 저장 이미지 조회에는 레퍼런스를 다시 선택하지 않는다. 서버 재시작 시 순환 목록은 초기화된다.

개인화 캐시에 `personal-body1`을 넣어 수치가 생성 지시에 빠져 있던 이전 결과를 새 요청에서 재사용하지 않는다. 사진·키·몸무게 변경도 기존처럼 캐시 키에 반영된다. 저장된 룩북 이미지 일괄 재생성·바로 보기 변경은 하지 않는다.

검증: 4단계·경계값·키 대비 몸무게·비정상 입력·개인화 off 유지·실제 이미지 요청 프롬프트/캐시 인자를 검사했고, 레퍼런스/바로 보기 회귀를 포함해 48개 테스트가 통과했다(`backend/tests/test_model_look.py`, `backend/tests/test_look_reference_pipeline.py`). 개인화 실제 얼굴 사진을 이용한 생성 품질 비교는 실행하지 않았다.

## 수치 기반 체형 우선 · 2026-10-08

공통 착장 생성(옷장 선택 코디·오늘 코디·직접 입혀보기)에서 개인화가 켜지고 키·몸무게가 전달되면 기본/스냅 체형보다 수치를 우선한다. 174cm·86kg는 풍성한 체형으로, 몸통·허리·복부·팔·허벅지와 옷의 떨어짐을 눈에 보이게 구성한다. 기존 전신 유지 문구를 얼굴 정체성 유지/몸 재구성으로 바꿨다. 구도 참조의 전신은 머리/어깨 부분만 사용해 마른 모델 몸을 그대로 복사하지 못하게 한다. 직접 입혀보기에서 얼굴 사진 없이 신체 수치만 쓰면 기본 캐릭터도 머리만 전달한다. 표정·시선·조명은 참조하고 몸 자세는 자연스럽게 구성하며, 직접 입혀보기의 선택 포즈를 별도 지시로 전달한다. 개인화 off와 보호된 바로 보기 생성/마스크/캐시는 유지한다.

개인화 생성 캐시는 `personal-body2`. 오늘 코디 표시 버전도 개인화에 한해 같은 버전을 사용하며, 개인정보 저장 시 얼굴/키/몸무게 변경은 표시된 오늘 착장 이미지를 비운다. 옷장 선택 코디의 개인화 캐시 키는 배포 환경에서도 사진과 프로필을 포함한다. 직접 입혀보기 작업 조회는 키·몸무게·얼굴 사용 여부·퍼스널 컬러를 반환하며 현재 설정과 다른 캐릭터 결과는 복원하지 않는다. 저장된 룩북 이미지는 일괄 재생성하지 않는다. 수치는 대략적인 외형 기준이며 실측 체형·정확한 핏 예측이 아니다.

근거: `backend/app/main.py` `_personal_look_body_note`/`_personal_look_framing_reference`/`generate_model_look_image`, `backend/app/closet_jobs.py` `JobStore.public`, `frontend/src/proto/09-app.jsx` `saveAccount`/`modelLookRevision`/`settingsKey`, `frontend/src/style/closet-studio.jsx` `matches`.
