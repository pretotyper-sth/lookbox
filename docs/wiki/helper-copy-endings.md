# 보조 안내 문구의 종결 형태

2026-10-11 현재 소스의 유사 사례를 비교했다. 비교 정리 후 사용자 승인으로 아래 두 예외 문구를 문장형으로 변경했다.

설명·사용법·설정 효과는 주로 해요체 문장이다. 제목·버튼·필드명·요약 상태는 명사/동작명으로 끝난다. 모든 문구가 하나의 형태로 통일된 것은 아니다.

| 위치 | 현재 문구 | 형태 | 근거 |
|---|---|---|---|
| 옷장 선택 안내 | 옷을 골라 정리하거나 코디를 추천받아요. | 문장 | frontend/src/proto/04-screens-ab.jsx:536 |
| 옷장 보관 안내 | 보관한 옷은 조합 추천에 쓰이지 않아요. 카드의 ···에서 다시 꺼내거나 삭제할 수 있어요. | 문장 | frontend/src/proto/04-screens-ab.jsx:530 |
| 직접 코디 만들기 | 옷장에 있는 아이템으로 원하는 조합을 만들어 룩북에 담아요. | 문장 | frontend/src/proto/05-screens-cde.jsx:954 |
| 마이 개별 AI 설정 | 옷장에서 개별 아이템으로 요청할 때도 적용돼요 | 문장 | frontend/src/proto/08-mypage.jsx:508 |
| 마이 얼굴·체형 설정 | 프로필 사진과 키·몸무게를 사용해요 | 문장 | frontend/src/proto/08-mypage.jsx:517 |
| 마이 새 아이템 설정 | 옷장에 없는 아이템을 넣어요 | 문장 | frontend/src/proto/08-mypage.jsx:531 |
| 피드 탐색 보조문구 | 저장하고 내 옷으로 리스타일해 보세요. | 문장 | frontend/src/style/experience.jsx:117 |
| 공유 피드 안내 | 공유된 스타일을 구경하고 내 옷으로 리스타일해 보세요 | 문장 | frontend/src/style/experience.jsx:147 |

권장: 보조 설명은 해요체로 유지하고 제목/버튼의 명사·동작명은 유지한다. 옷장 축약안은 「옷을 골라 정리하거나 코디를 추천받아요.」, 피드 탐색은 「저장하고 내 옷으로 리스타일해 보세요.」. 실제 모바일 한 줄 여부는 적용 시 폭별 검증이 필요하다. 기존 축약은 길이만 줄이고 설명 종결 톤을 놓친 사례다.
