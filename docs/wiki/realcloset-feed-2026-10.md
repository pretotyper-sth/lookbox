# RealCloset — 룩북 복원과 별도 피드 (2026-10-02)

사용자는 룩북의 기능 과밀, 첫 행동/온보딩의 불명확함을 지적하고 기존 룩북 보존 + 별도 피드 + 조금 더 젊은 톤을 요청했다. [[realcloset-style-studio-2026-10]]의 기능은 피드로 옮기고 기존 `LookbookScreen` 등록을 복원했다.

## 현재 정보 구조

룩북은 기존 저장 추천 코디만 표시한다. 피드는 기본 진입이 둘러보기이며 주요 탭은 둘러보기/내 스타일 2개다. 영감·기록·취향 프로필은 내 보관함을 열어 접근한다. 기존 저장 코디와 새 창작 스타일의 데이터도 분리돼 있다.

첫 방문은 샘플 1개와 “이 룩으로 시작하기”를 제시한다. 고르기 → 옷/배경을 내 취향으로 → 저장/선택 공유의 3단계가 보인다. 꾸미기와 이름/메모/무드 저장을 별도 편집 단계로 나누고, 배치 상세/착장 사진은 접는다. 신규 스타일은 비공개 저장 후 친구에게 공유/나만 보기 중 선택한다. 최초 안내를 넘기거나 저장하면 안내를 숨기며, 내 보관함의 처음 사용 가이드에서 다시 연다. 최초 안내 중에는 주간 참여 주제를 숨겨 동시 행동 요청을 줄인다.

기존 아이보리/차콜/타이포/셸을 유지하고 피드에만 세이지·샌드 포인트와 조금 부드러운 카드/짧은 문구를 적용했다. 공개 룩 탐색, 실제 반응, 원작 출처를 남기는 리믹스, 내 옷 우선 치환, 영감 구분, 링크 공유/투표/제안 기능은 유지한다. 가짜 인기도를 추가하지 않는다.

## 사용자 정정: 만들기 컬러와 서비스 착장 샘플 (2026-10-06)

직전 피드 톤 변경은 사용자 요청을 잘못 해석했다. 피드 만들기/팔로우 버튼의 오렌지·둥근 스타일과 `AI 착장 예시` 태그를 되돌렸고, mood 파생 JPEG 8개를 제거했다. 샘플 배경·큰 타이포·회전 등 각 사용자의 창작 스타일은 유지한다. 색상 통일 대상은 만들기 편집기의 UI다. `story-editor.css`에서 라임 선택 상태·배지·모바일 게시·업로드/격자/포커스를 기존 웜 뉴트럴·#BF603D 포인트로 변경했다. 창작용 배경/스티커 색상은 계속 선택할 수 있다.

새 샘플은 실제 서비스 `generate_model_look_image`의 현재 Flare high, A 그레이지 배경, 4:5 전신 생성 경로로 만든 남성 3장·여성 1장이다. 라이브 옷장 상품컷을 입력했고 `assets/mood` 이미지를 사용하지 않았다. 생성 결과/상품별 브랜드·기록 가격은 `frontend/public/studio-assets/feed-samples/{stripe,black,weekend,stripe-woman}.png`와 `sources.json`에 저장했다. 라이브 저장 이미지를 일괄 수정하거나 운영 계정 크레딧/DB를 변경하지 않았다. 샘플 가격은 등록된 구매가 기록이며 미등록 값은 만들어 넣지 않는다. 주말 블루종/치노는 과거 등록한 상품 기록을 활용했다.

`model.js` SAMPLE_LOOKS는 착장 포스터, 착장+상품, 상품컷 가격 기록, 여성 착장, 반복 코디, 자유 콜라주, 상품 아카이브, 남녀 같은 옷 비교의 8개 편집 가능한 레이아웃이다. 기존 editorial-v4 ID를 유지해 반응/팔로우 연결을 보존한다. 추천/저장 코디의 만들기 진입은 `outfitLook`으로 실제 lookImg와 상품 브랜드/가격을 유지하며, 상품컷만 있는 경우 기존 `editorialSlots`를 활용한다. `story-editor.jsx` 옷장 도구의 브랜드·가격 표시, `collage-canvas.jsx` 정보 라벨, `model.js` PNG 출력, `style_studio.py` 저장 필드/샘플 이미지 허용 경로를 연결했다.

로컬 데스크톱에서 신규 샘플과 오렌지 편집기 표시를 확인했다. 모바일 게시/도구 선택 색상도 같은 포인트를 사용한다. 라이브 배포 없음.
