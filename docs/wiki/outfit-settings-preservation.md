# 기존 AI 착장 보존과 초기 추천 대기 단축 (2026-10-16)

설정 변경은 다음 생성 요청부터 반영한다. 완성된 `lookImg`는 개인정보 저장,
개인화 켜기/끄기, 개인화 설정 저장, 프롬프트 revision 변경으로 지우지 않는다.
생성 중인 요청도 시작 당시의 요청 본문을 사용한다. 명시적으로 새 코디를
요청하면 현재 설정이 전달된다. 기존 서버 이미지 캐시 키는 유지한다.

근거: `frontend/src/proto/09-app.jsx`의 `saveAccount`,
`onTogglePersonalModelLook`, `savePersonalModelLook`, `applyModelLooks`.
회귀 검증: `frontend/tests/model-look-settings.test.mjs` — 실제 저장 핸들러를
실행해 이미지 보존과 새 설정 저장을 검증한다.

상품컷 추천은 `recommend_closet` 규칙 계산이며 GPT 응답을 기다리지 않는다.
최근 제외 조합·피드백·최근 제안 조회를 3개 스레드로 겹쳐 처리한다.
세 결과를 모두 받은 뒤 같은 입력으로 추천하므로 점수·제외·다양성·품질은 유지한다.
모델, high 품질, 출력 해상도와 비용 감사 로그는 변경하지 않았다.
`backend/tests/test_live_coordinate_pipeline.py`의 barrier 검증은 세 조회가
동시에 진행되고 각각의 결과가 유지되는지 확인한다.
서버 cold start 또는 이미지 공급자 첫 요청 지연이 원인이라는 실측 증거는
이번 점검에 없으며, 최초 5초 이내를 보장하는 변경은 아니다.

## 품질 점검 (미배포 제안)

`backend/app/main.py:_pair_score`는 격식·스타일·톤·패턴·핏·계절,
얼굴 가까운 상의의 퍼스널컬러·선호 팔레트·날씨를 점수화한다.
`recommend_closet`은 최근 평가와 기본 조합 다양성도 반영한다.
키/몸무게는 착장 이미지 생성에 전달되지만 상품컷 조합 점수에서 실제 치수
적합성을 검증하지 않는다. 키/몸무게만으로 개별 의류 실측 핏을 보장할 수 없다.
지정된 테스트 계정 53벌의 메타데이터에서 메리노울 니트가 면 티셔츠로
분류된 사례를 확인했다. 속성 정확도와 레이어링은 후속 개선 후보이며 이번에는
추천 로직과 계정 데이터를 수정하지 않고 실제 옷 사진 기반 예시만 생성한다.

검증: 관련 Python 10건·Node 12건 통과, Vite 프로덕션 빌드 통과.
전체 Node 테스트 40건 중 기존 6건 실패는 HEAD 기준에서도 동일 재현
(import.meta 테스트 실행기 4건, 기존 AI 표시 문구/레이아웃 검증 2건).
