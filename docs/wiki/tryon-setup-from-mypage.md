# 바로 보기 설정 행은 없다

마이페이지 설정에는 `바로 보기 이미지` 행이 없다. 착장은 프로필 사진이 아니라
성별만 맞춘 룩북 모델로 보여 준다. 바로 보기는 추가 시트 탭에서만 사진을 올린다.

추가 시트 바로 보기 탭의 미리보기는 비어 있고 「프로필 사진 올리기」다.
저장된 `prefs.tryOnBody`로 채우지 않는다.

바로 보기의 구멍은 편집 화면이 아니라 카메라에서 뚫린다. 전신 사진에서 옷 자리만
투명하게 비워 후면 카메라가 그 사이로 비친다 (`10-tryon.jsx` `punchBody`).

근거: `frontend/src/proto/08-mypage.jsx` 설정 카드; `04-screens-ab.jsx` `tryOnPreview`.
