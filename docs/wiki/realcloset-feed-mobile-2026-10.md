# 피드·모바일 꾸미기 재구성 — 2026-10-02

사용자가 PC 기반의 복잡하고 진지한 경험을 지적하고, 게시물 하나씩 세로로 보는 피드, 설명보다 바로 만들기, 모바일 중심 스토리 편집기, 원터치 재료 삽입, 불필요한 이동 버튼 제거를 요청했다. [[realcloset-style-lab-2026-10]]의 첫 편집기 배치를 대체한다.

## 현재 경험

`frontend/src/style/experience.jsx`의 발견 피드는 3열 카드 대신 한 줄 세로 스트림이다. 모바일은 사진이 화면 가로를 채우며 작성자 → 코디 → 좋아요/의견/저장/이 룩으로 만들기 → 짧은 캡션 순서다. PC는 기존 사이드바 안에서 폭 520px 스트림을 가운데 배치한다. 상단 설명/첫 안내/주간 주제 박스를 제거하고 피드·만들기·탐색 탭만 남겼다. 공개 게시물 좋아요는 실제 API와 연결되며 샘플에 가짜 반응을 붙이지 않는다. 내 스타일/영감 보관함은 기존 그리드를 유지한다.

`frontend/src/style/story-editor.jsx`에서 650px 이하 모바일과 PC 분기를 명시한다. 모바일은 body 포털의 전체 화면: 어두운 바깥 배경, 캔버스, 상단 닫기/되돌리기/다시 하기/완료, 하단 8개 도구. 도구는 최대 40dvh 재료 서랍을 열며 선택하면 즉시 삽입되고 서랍이 닫힌다. 캔버스 위 드래그로 이동, 선택 모서리 손잡이로 크기·회전, 두 손가락 핀치/회전 처리. 모바일 선택바는 복제/삭제 중심으로 줄였으며 PC에는 크기/회전/투명도 슬라이더를 유지한다. 앞/뒤/좌우 이동 버튼은 양쪽에서 제거했다. PC는 캔버스와 재료를 두 패널로 나누고 전체 화면 모바일 구조를 축소하지 않는다.

`frontend/src/style/collage-canvas.jsx`에서 이동, 모서리 변형, 2개 포인터 핀치/회전, 키보드 손잡이 조작을 처리한다. ArrowUp/Down은 크기, ArrowLeft/Right는 회전이다. 한 제스처에 하나의 되돌리기 단위를 만든다.

## 재료

- 공식 OpenMoji 17.0.0 원본 컬러 SVG 1,032개: 표정, 동물·자연, 음식, 여행, 취미, 물건. 원본 라이선스/출처 유지. 100개씩 더 보기를 제공해 처음부터 1,000개 이미지 DOM을 만들지 않는다. 같은 원본을 둥실/두근/흔들 레이어로 삽입하는 무빙 탭도 추가.
- 기존 오리지널 콜라주 84개, 시스템 이모지 144개 유지. Quick Type 76개를 여러 글꼴/윤곽/라벨/그림자 조합으로 바로 삽입.
- GIPHY 공식 공개 reactions 페이지에서 확인한 23개의 공개 GIF ID를 원터치 목록으로 제공. URL 입력 없이 공개 상세 페이지에서 읽은 실제 og:image 미리보기를 눌러 삽입한다. 미리보기 URL은 반환된 원본 그대로 사용하고 삽입 결과는 공식 embed 플레이어다. 이미지 원본을 내려받거나 캐시하지 않는다. `frontend/src/style/giphy-catalog.js`에 원래 공개 링크와 ID 보관.
- 이미지 탭은 내 사진 업로드를 우선하고 기존 프로토타입 스타일 사진 11개를 바로 삽입하는 팔레트 제공. 원본 주소는 접힌 보조 입력으로 내림. 밈 템플릿 12개 유지.

키 없이 공개 GIF 픽을 사용할 수 있다. 전체 GIPHY 검색은 여전히 웹 API 키 연결이 필요하며 실제 검색 키는 미연결이다. 공식 픽은 API 검색 결과로 가장하지 않고 별도로 표시한다. GIPHY 임베드의 PNG 제외와 파일 업로드 자동 검증 제약은 기존 문서와 같다.

## 검증

모바일 390×844에서 원터치 스티커/GIF/이미지/Quick Type 삽입 → 재료 서랍 닫힘 → 완료 → 비공개 저장을 실행했다. 다시 수정해서 실제 포인터 드래그로 사진/텍스트/GIF/스티커를 옮겼고 GIF 모서리 드래그로 폭 28% → 40.54%, 회전 1.895° 적용을 확인했다. 키보드 손잡이도 이미지 38% → 40%, 회전 5° 확인. 저장 후 다시 열린 스타일에서 사진/GIF/텍스트/스티커 유지. 실제 두 손가락 입력은 미검증이며 포인터 처리 구현만 있다. 모바일 clientWidth/scrollWidth는 모두 390px. 데스크톱 실제 좋아요 변경 확인.

백엔드 6개/프런트 5개 테스트, 변경 모듈 lint, production 빌드, diff whitespace 검사 확인. 개발 전용 UI는 로컬 브라우저로 확인. 바로 보기 체크포인트 변경·라이브 배포 없음.
