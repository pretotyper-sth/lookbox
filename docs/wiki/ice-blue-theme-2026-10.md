# 아이스 블루 테마 검토 — 2026-10-07

상태: 2026-10-07 사용자 요청으로 색상 적용을 철회했다. 서비스는 요청 전 아이보리·차콜로 복원했고, 공개 비교 페이지와 이미지 시안 경로는 제거했다. 아래 내용은 검토 이력이다.

사용자는 AI 코디의 기존 그레이지 배경을 더 화사한 흰색/블루 계열로 바꾸고, 서비스 화면도 같은 계열의 다른 톤으로 맞춰 보길 요청했다.

내장 이미지 생성 도구로 실제 서비스 생성 샘플 stripe.png의 배경만 옅은 아이스 블루로 편집했다. 결과는 docs/research/ice-blue-theme-2026-10/outfit-ice-blue-preview.png. 이 시안은 추천 생성 모델/프롬프트를 수정한 결과가 아니며, backend 생성 프롬프트·캐시와 기존 저장 착장은 이번 작업에서 바꾸지 않았다.

로컬 서비스는 블루 화이트 #F2F7FC 바탕, #FFFFFF 카드/시트, #F8FBFF 보조 면, #E4EDF6 상품판, #2D527A 버튼, 슬레이트 글자로 맞췄다. 공통 토큰과 실제 앱의 TONES 기본값을 함께 바꿨다. 앱은 실행 시 TONES를 inline CSS로 적용하므로 proto.css만 변경하면 기존 ivory가 덮어쓴다. 근거: frontend/src/proto/proto.css:81, frontend/src/proto/09-app.jsx:14, frontend/src/proto/09-app.jsx:30. 피드·알림·꾸미기 UI의 고정 아이보리/세이지 표면도 같은 계열로 정리했다. 사용자 작성 캔버스 내용/색상 데이터는 변경하지 않았다.

정적 WebP, 원본 이미지/썸네일, 캐시, 우선/지연 로딩, 서비스 워커, API 동작을 이번 변경에서 수정하지 않았다. 보호된 바로 보기 프레임/마스크/인물 생성도 변경하지 않았다. 서비스 코디 배경과 모든 무드 이미지의 일괄 적용은 아직 진행하지 않았다.
