# RealCloset — 창작·공유 로컬 체험과 시장 진입 (2026-10-02)

사용자 요청: 개멋 분석의 제안을 반영한 포지셔닝맵과, 현행 RealCloset 레이아웃·톤을 유지한 데스크톱/모바일 로컬 체험. [[gamut-benchmark-2026-10]]의 전략 제안을 이번 요청으로 구현하도록 승인받았다.

## 전략

진입 메시지: “내 옷으로, 나만의 취향을. 친구의 스타일을 내 방식으로 만들고, 내일 입어보세요.” 초기 고객은 전체 MZ가 아니라 코디·무드보드를 저장/공유하고 보유 옷을 재조합하려는 사람으로 좁혀 검증한다. 샘플 첫 작품 → 내 옷으로 교체 → A/B 질문 → 반응/영감/리믹스 → 다음 작품/착용 기록을 연결한다.

가로축은 실제 내 옷으로 실행 가능성, 세로축은 자기표현·반응·관계 가치다. 기존 RealCloset의 실용 중심에서 표현·관계 가치가 커지는 방향을 제안한다. Whering·Indyx·Acloset도 공유/협업 기능을 갖고 있으므로 공백 시장이라고 주장하지 않는다. 좌표는 관찰에 근거한 정성적 해석이며, 제안 위치는 목표이지 경쟁 우위의 입증이 아니다.

`docs/research/realcloset-positioning-2026-10/positioning.html`에는 클릭 가능한 맵, 서비스별 배치 근거, 초기 취향 모임 모집과 4주 검증안, 공식 출처를 담았다. PNG/SVG도 같은 폴더에 있다. 로컬 URL `/positioning.html`.

## 구현

후속 사용자 요청으로 정보 구조를 수정했다. 현재는 기존 룩북을 그대로 복원하고 창작/공유를 별도 피드로 분리한다. 상세: [[realcloset-feed-2026-10]]. 아래 첫 항목은 초기 구현 기록이다.

- 기존 데스크톱 사이드바·모바일 하단 메뉴·추천/구매 검토 흐름을 유지하고 룩북에 내 스타일/발견/영감/기록/프로필을 추가했다. 기존 추천 룩북은 접어서 그대로 접근 가능하다.
- 샘플 시작, 임시 저장/복귀, 아이템 드래그·크기·회전·순서·위치 조절, 위치/크기를 유지하는 교체, 배경·글자·장식·이름·메모·무드/상황, PNG 내보내기를 제공한다.
- 샘플/실제 보유/구매 관심/영감을 구분한다. 리믹스는 같은 분류의 실제 보유 옷을 우선 치환하며, 없는 아이템은 영감/샘플로 남긴다. 영감 저장은 기존 보유 옷 추천 데이터에 들어가지 않는다.
- 나만 보기/링크 받은 사람/발견 공개, 착장 사진 별도 동의, 리믹스 허용, 공유 링크, 실제 좋아요·열람·A/B 투표·친구 제안을 저장한다. 비공개 전환 시 링크를 종료한다. 공개 응답에서 가격·옷장 전체·개인 설정을 제외한다.
- 무드/상황 탐색, 영감 룩/아이템 저장, 취향 팔로우/필터/게시물 숨김, 원작 출처, 첫 주제 “새 옷 없이 다른 분위기”, 개인 착용 기록과 기록 기반 프로필 집계를 제공한다. 에디터 샘플에는 활동 수치를 만들지 않는다.
- 추천 상세에서 “이 코디로 내 스타일 만들기”를 연결했다. 추천에 섞인 구매 관심 아이템을 보유 옷으로 표시하지 않는다. 추천 AI 착장 사진을 공개용 사진으로 자동 전달하지 않는다.

구현 위치: `frontend/src/style/experience.jsx:1`, `frontend/src/style/model.js:1`, `frontend/src/style/experience.css:1`, `backend/app/style_studio.py:1`. 진입: `frontend/src/main.jsx:60`, 추천 연결: `frontend/src/proto/05-screens-cde.jsx:1646`, 샘플 진입: `frontend/src/proto/07-onboarding.jsx:266`. 개발 서버의 `/api/studio`만 8123으로 프록시한다(`frontend/vite.config.js:10`).

## 실행·범위

백엔드는 `STYLE_STUDIO_LOCAL=1 AI_TEST_MODE=1 .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8123`, 프런트엔드는 `npm run dev -- --host 127.0.0.1 --port 5173`로 실행한다. 새 체험은 Vite 개발 환경에서만 활성화하며, 백엔드 라우터도 `STYLE_STUDIO_LOCAL=1`일 때만 붙는다. 기존 서비스 계정 데이터와 분리한 SQLite(`backend/.local/style-studio.sqlite3`, Git 제외)에 저장한다. 소유권은 브라우저별 로컬 체험 식별자로 구분한다.

직접 체험 URL: `http://127.0.0.1:5173/?screen=lookbook&ws=empty&saved=empty`. 모바일 미리보기 `/responsive.html`은 같은 앱을 실제 390×844 iframe으로 실행한다. 실험용 데이터가 일반 옷장에 자동 등록되지 않는다.

공유는 현재 같은 컴퓨터의 로컬 체험이다. 외부 유입 실험을 하려면 서비스 계정 인증, 외부 공유 호스트/미리보기, 신고·운영·반응 남용 방지, 이벤트 수집을 연결해야 한다. 공개 피드의 팔로우·숨김은 작동하지만 알림/신고 처리를 구현한 것으로 표현하지 않는다. 공유 링크 종료는 이미 내려받거나 영감으로 복사한 사본까지 회수하지 않는다. 착장 사진의 자동 얼굴 가리기는 이번 체험에 포함하지 않았고 사진 공개는 기본 해제한다.

보호된 바로 보기의 카메라/마스크/프레임/캐시/생성/검증 동작은 수정하지 않았다. 기존 미커밋 변경도 보존했다.

## 검증

프런트 빌드·새 모듈 lint·diff 공백 검사 통과. 백엔드 4개 테스트: 개인 저장 격리/공개 필드 제거, 링크 비노출/종료/사진 동의, 방문자당 중복 반응 방지/투표 변경, 기록·영감과 보유 옷 분리. 모델 2개 테스트: 보유 옷 중복 치환 방지/원작 보존, 새 버전의 비공개·사진 공개 초기화.

실제 UI에서 비공개/공개 저장, 새 버전, 배경/장식, 공유 링크 열람, 좋아요/친구 제안, A/B B=1표, 모바일 교체, 1000×1250 PNG 다운로드, 빠른 비공개 기록 저장을 확인했다. 모바일 DOM은 폭/scrollWidth 390, 높이 844로 가로 넘침이 없다. 공유 페이지의 원래 전역 overflow 제한으로 아래 투표에 접근하지 못하던 문제를 자체 스크롤로 수정했다. 결과 이미지: 같은 연구 폴더의 `desktop.jpg`, `mobile.jpg`, `shared-vote.jpg`.

랜딩의 개발 환경 문구/주 CTA도 “내 옷으로 나만의 취향”과 샘플 첫 제작으로 연결했다. 기존 랜딩 구조/캐러셀/로그인 및 옷장부터 시작하는 경로를 유지하며, 프로덕션에서는 기존 문구와 시작 경로가 유지된다. `frontend/src/proto/07-onboarding.jsx:191`.
