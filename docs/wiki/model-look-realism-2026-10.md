사용자는 어서옷세요 YouTube·무신사 스냅처럼 인물·표정·포즈·배경이 다양한 자연스러운 착장을 요청했다. 무신사 AI 스튜디오 시안을 승인한 뒤 실제 서비스 생성 경로에 적용하고 위아래 여백을 조금 늘렸다.

변경 전 코드 기본값은 `gpt-image-2`, 착장 품질 기본값은 `medium`이었다. `_model_look_prompt_with_reference`는 같은 사람과 스튜디오 구도를 유지하도록 지시한다. 따라서 다양한 스냅을 만들려면 모델 변경과 함께 기준 사진 선택·구도 지시를 바꿔야 한다.

OpenAI는 2026-09-08 GPT Image 2.5 Flare·Sunburst를 발표했다. 공식 안내는 자연광·질감·레퍼런스 유지 개선을 설명한다. 출처: https://openai.com/index/introducing-chatgpt-images-2-5/

대화 내 생성 도구로 개별 거리·계단 착장 시안을 만들었으나 도구에 모델 선택 인자가 없으므로 특정 2.5 모델의 검증 결과로 취급하지 않는다. 실제 옷장 상품의 디테일 보존도 별도 검증이 필요하다. 바로 보기 체크포인트와는 별개인 추천 AI 착장 검토다.

## 사용자 정정: 무신사는 AI 생성 코디 레퍼런스

사용자는 무신사 쪽은 실제 사람 스냅이 아니라 AI 생성 이미지를 뜻했다고 정정했다. Chrome에 열린 https://www.musinsa.com/snap/1554075079328664012 의 무신사 코디 피드에서 이미지 하단 `AI로 생성`과 `#AI무신사코디`를 확인했다. 피드의 회색 스튜디오 AI 이미지를 직접 확보해 생성 도구의 이미지 입력으로 사용했다. 같은 네이비 가디건 코디에 목 뒤 손·교차한 발·소매 정리의 세 구도를 새 후보로 생성했다. 핵심은 밝고 차가운 회색 배경, 부드러운 조명, 선명한 의류 실루엣과 다양한 모델 자세다. 무신사의 생성 모델이나 후처리 과정은 공개 화면만으로 확인되지 않았다.

## 서비스 적용

Chrome 무신사 공식 AI 코디 프로필에서 37장을 확보했다(남성 16·여성 21). 12장은 1000px 원본, 나머지는 피드 썸네일이다. `backend/assets/look-references/catalog.json`에 실제 이미지 주소·출처 페이지·성별·포즈·수집 날짜·크기를 보관한다. `backend/app/look_references.py:29`는 계정·성별별로 섞은 전체 목록을 소진한 뒤 다시 섞는다. 같은 목록 안에서는 중복 선택하지 않고 다음 목록 첫 장도 직전 장과 겹치지 않는다. 목록은 프로세스 메모리에 있어 서버 재시작 시 초기화된다.

추천 착장 기본값은 `gpt-image-2.5-flare` + `high`(`backend/app/main.py:63`). 개인화 off는 선택한 AI 인물·포즈와 옷장 상품컷, on은 사용자 얼굴·스냅 구도·상품컷 순서로 전달한다(`backend/app/main.py:5282`). 옷장에 없는 레퍼런스 의류·소품과 AI 표시를 제외하고 실제 상품의 로고는 보존하도록 지시한다. 새 캐시 버전 `model-studio1`을 사용하며 저장된 같은 코디는 레퍼런스 선택·AI 호출 전에 반환한다. 이미 저장한 코디를 일괄 재생성하지 않는다.

구도는 78~80% 전신 높이, 위 약 11%·아래 약 9% 여백으로 지시한다(`backend/app/main.py:4720`). 기존 4:5 결과에 `_frame_studio_look`이 비율을 유지하며 축소·중앙 배치·배경 확장을 적용한다(`backend/app/main.py:5190`). 인물을 확대하지 않는다. 바로 보기 모델·마스크·캐시·프레임은 수정하지 않았다.

검증: 추천 착장·레퍼런스 순환·실제 요청 인자/개인화/캐시·바로 보기 회귀 44개 테스트 통과. 실제 서비스 `generate_model_look_image`에 예시 가디건·데님·신발 상품컷을 입력해 Flare high 생성 성공(약 17.3초); 캐시·크레딧·업로드만 로컬 대체했다. 1024×1280 결과에서 전신 높이 약 80%, 손 주머니·교차한 발·측면 시선과 니트/데님 질감을 확인했다. 실제 계정 과금·운영 배포 이후 생성은 별도다.
