# 판 정리는 칠하지 말고 옮겨야 한다 — 신발 옆 깨짐의 원인

`_flatten_look_plate`가 통과한 픽셀을 전부 `#E5E3DE`로 못박아서, 발밑 접지
그림자의 밝은 구간이 판 색으로 먹혔다. 그림자는 부드러운 그라데이션인데
임계값을 넘는 지점에서 잘려 계단·얼룩 경계가 생겼고, 그게 사용자가 본
"신발 쪽이 깨진다"였다(2026-09-02).

실측(생성 결과 1장, 신발·그림자 구간):

| | 원본 대비 최대 변화 | 6단계 이상 훼손된 픽셀 |
|---|---|---|
| 못박던 코드 | 19 | 1359 |
| 지금 | 18 | 175 |

지금 규칙은 두 갈래다.

- 목표색보다 **밝은** 픽셀(= AI가 잘못 깔아 둔 다른 톤, 밴딩) → `#E5E3DE`로 못박는다.
- 목표색보다 **어두운** 픽셀(= 그림자) → 귀퉁이 실측 배경색과 목표색의 차이만큼만
  평행이동한다. 상대 명암이 남아 그라데이션이 끊기지 않는다.

배경이 목표색과 거의 같은(실제 출력은 228 vs 229) 보통 상황에서는 보정량이
1단계라 두 갈래의 경계에 단차가 사실상 없다. 다만 **밝은 쪽으로 크게 틀어진
판 + 그림자**가 겹치면 경계에 보정량만큼 단차가 남는다. 그 조합은 아직 실물로
못 봤고, 보면 여기부터 다시 본다.

회귀 테스트는 `test_flatten_keeps_contact_shadow_gradient` — 실제 출력과 같은
조건(배경이 목표색보다 1단계 어두움)에서 그림자 줄의 인접 픽셀 낙차가 2 이하여야 한다.
