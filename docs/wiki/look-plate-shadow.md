# 착장 배경은 카드 색으로 통일한다 — 생성본 바닥선을 제거한다

2026-09-13부터 착장 결과의 배경은 카드와 같은 `#E5E3DE` 단색으로 맞춘다.
`_normalize_look_background`가 행별 가장자리 색과 다른 인물 픽셀만 보존하고,
생성본에 남는 벽·바닥 경계선을 배경으로 제거한다.

## 무엇이 깨졌나

판 밝기(luma 227)를 기준으로 **밝으면 못박고, 어두우면 평행이동**하는 두 갈래였다.
배경이 판 밝기 근처에서 오르내리면 두 갈래가 픽셀 단위로 번갈아 걸려 얼룩진 띠가
생긴다. 사용자가 세 번에 걸쳐 지적한 "신발 쪽이 깨진다"가 이거였다.

재현(합성 이미지, 위에서 아래로 236→202로 어두워지는 스튜디오 배경):

| | 결과 |
|---|---|
| 평탄화 전 | 매끈한 그라데이션 |
| 평탄화 후 | 배경 밝기가 227을 지나는 줄에 얼룩진 가로 띠 |

앞선 두 번의 수정(칠하기 → 평행이동)은 이 구조를 그대로 두고 임계값만 옮긴
것이라, 띠가 생기는 위치만 바뀌었다. 임계값으로 그라데이션을 분류하는 한
어딘가에는 계단이 남는다.

## 이전 동작

이전에는 배경을 레퍼런스 스튜디오 그대로 두고 후처리는 4:5 자르기만 했다.

같은 신발 영역(500x180)에서 이웃 픽셀과 5단계 이상 튀는 배경 픽셀 비율:

| | 비율 |
|---|---|
| 예전 파이프라인 (사용자 제보 2장) | 13.6% / 13.1% |
| 지금 (실제 생성 1장) | 1.9% |

단색 판을 포기해도 카드에 배경이 둘로 보이지 않는다. 이미지가 카드를 꽉 채우고
(`objectFit: cover`), 인물이 커서 넣기로 갈 때도 가장자리를 늘리지 않는다.
원본에서 4:5 창을 잡아 스튜디오 픽셀을 그대로 쓴다(`_fit_look_to_card`, 2026-09-06).
이미 늘려 둔 이미지는 프론트가 좌우 9%를 잘라 띠를 가린다.

인접 낙차 2 이하), `test_fit_pads_with_backdrop_not_flat_plate`(여백이 판 단색이 아니다).
