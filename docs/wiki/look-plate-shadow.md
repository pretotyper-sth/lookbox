# 착장 배경은 손대지 않는다 — 기준 스튜디오를 보존한다

2026-09-14부터 착장 결과에 배경 분리·평탄화 후처리를 적용하지 않는다. 기준 인물
이미지(Image 1)의 스튜디오와 조명을 그대로 보존하도록 모델에 지시한다. 단, 생성본에
남은 얇고 곧은 가로 경계선은 약한 바닥선까지 인물과 무관한 배경 픽셀에서 보간해 없앤 뒤 4:5 프레이밍을
적용한다.

## 무엇이 깨졌나

판 밝기(luma 227)를 기준으로 **밝으면 못박고, 어두우면 평행이동**하는 두 갈래였다.
배경이 판 밝기 근처에서 오르내리면 두 갈래가 픽셀 단위로 번갈아 걸려 얼룩진 띠가
생긴다. 사용자가 세 번에 걸쳐 지적한 "신발 쪽이 깨진다"가 이거였다.

재현(합성 이미지, 위에서 아래로 236→202로 어두워지는 스튜디오 배경):

| | 결과 |
|---|---|
| 평탄화 전 | 매끈한 그라데이션 |
| 평탄화 후 | 배경 밝기가 227을 지나는 줄에 얼룩진 가로 띠 |

앞선 두 번의 수정(칠하기 → 평행이동)은 이 구조를 그대로 두고 임계값만 옮긴
것이라, 띠가 생기는 위치만 바뀌었다. 임계값으로 그라데이션을 분류하는 한
어딘가에는 계단이 남는다.

## 왜 단색 합성이 다시 깨졌나

행별 가장자리 색과 다른 픽셀만 인물로 남기는 방식은 옷뿐 아니라 인물 주변의
접지 그림자·스튜디오 질감도 전경으로 오판한다. 그 결과가 카드색 위에 번짐·얼룩으로
남았다. 단색·흰색 배경 요구도 모델이 기준 이미지와 다른 스튜디오를 다시 그리게
하는 충돌 지시였다.

같은 신발 영역(500x180)에서 이웃 픽셀과 5단계 이상 튀는 배경 픽셀 비율:

| | 비율 |
|---|---|
| 예전 파이프라인 (사용자 제보 2장) | 13.6% / 13.1% |
| 지금 (실제 생성 1장) | 1.9% |

카드 배경색과 생성 이미지의 배경색을 억지로 일치시킬 필요는 없다. 이미지가 카드를
꽉 채우고(`objectFit: cover`), 인물이 커서 넣기로 갈 때도 가장자리를 늘리지 않는다.
원본에서 4:5 창을 잡아 스튜디오 픽셀을 그대로 쓴다(`_fit_look_to_card`, 2026-09-06).
이미 늘려 둔 이미지는 프론트가 좌우 9%를 잘라 띠를 가린다.
