# add-item-bulk

아이템 추가 → URL 탭은 한 줄 `input`을 쌓는다. `+ 주소 추가`로 칸을 늘리고, 여러 줄·여러 주소를 붙여넣으면 칸이 늘어난다. URL 탭이 열려 있으면 입력칸 포커스 없이도 ⌘/Ctrl+V로 주소가 칸에 들어간다. 입력·추가 버튼이 168px 박스를 넘으면 박스 안에서만 스크롤한다. 칸이 하나면 바로 추출하고, 둘 이상이면 후보 목록을 보여 고른 뒤 **기본은 사진과 같이 하나씩 확인·담기**. 「확인 없이 바로 담기」를 켜야 예전처럼 일괄 자동 등록. (`frontend/src/proto/04-screens-ab.jsx` `urls`, `runBulkReview`, `bulkAuto`)

사진·URL 탭 스테이지는 168px, CTA 위·아래 보조 슬롯은 각각 44px(`--s4` 16 + 안내 행 28)으로 고정한다. 구매내역·바로 보기 박스는 CTA 위 슬롯을 포함해 212px이고 CTA 아래 슬롯은 그대로 렌더해, 사진·URL·구매내역 탭을 바꿔도 시트와 CTA 위치가 같다. 모바일 구매내역은 카드 안에서 바로 보기와 같은 글꼴로 「구매내역은 PC에서 불러올 수 있어요」를 안내하고, CTA 아래에서 PC 로그인 조건을 안내한다. 바로 보기 칸 안에는 계정 프사 원형만 두고, 오류 문구도 이 칸 안에 넣는다. 조합 추천받기(고민 중)는 CTA 아래 빈 힌트 칸을 넣지 않는다. 입력 단계는 본문 아래 패딩 12px, BottomSheet는 safe-area만 (`tightBottom`). 크롬 「이미지 복사」의 HTML `data:image` 붙여넣기도 캡처 PNG와 같이 사진 탭으로 받아 처리한다(2026-09-14).

구매내역 탭 안내: PC는 「쇼핑몰을 고르면 로그인 화면이 열려요.」, 모바일 웹은 픽토그램 없이 「구매내역은 PC에서 불러올 수 있어요」와 CTA 아래 PC 로그인 조건만 안내한다. CTA는 데모에서도 실제 서비스와 같은 「주문 내역 가져오기」 문구·낮은 대비를 유지한다. 실제 `disabled` 속성은 클릭을 막으므로 쓰지 않고, 탭하면 「구매내역은 PC에서만 불러올 수 있어요」 토스트를 띄운다. 구매내역은 잠금 기능이 아니라 기기 제약이므로 탭·CTA에는 `bag` 아이콘을 쓴다. 로그인 뒤에는 주문내역을 읽고 사용자가 고른 옷만 담으므로, CTA 아래 문구는 「주문내역에서 옷을 골라 담아요」다. 수집 목록은 「취소 / N개 담기」로 행동을 분명히 하고, 다른 소스 탭을 다녀와도 유지한다. 상세 확인에서 뒤로 돌아오면 완료된 수집 상태를 비우고 처음 쇼핑몰 선택 화면을 복원한다. 「다른 쇼핑몰」에서도 현재 구매내역을 비우고 몰 선택으로 돌아간다. 흐름은 [[order-import-webview]].

URL·사진 추출 뒤 `register`의 「담고 완료」는 상세 입력(메모) 아래, 시트 본문 안에 둔다. 상세 시트의 「저장」과 같다. 스크롤 밖 고정·sticky를 쓰지 않는다. (`frontend/src/proto/04-screens-ab.jsx` `advance`)

URL은 한 번에 최대 20개까지 입력할 수 있다. 「주소 추가」를 누르면 목록을 아래로 스크롤하고 새 입력칸에 포커스해 버튼을 계속 보이게 한다. 다중 URL 붙여넣기가 20개 한도를 넘으면 초과 안내를 표시한다. (`frontend/src/proto/04-screens-ab.jsx` `URL_ROW_MAX`, `addUrlRow`, 2026-10-11)

여러 URL을 순차 확인할 때 같은 호스트에서 추출한 브랜드가 다른 상품에 비어 있으면 해당 브랜드를 미리 채운다(편집 가능). 각 상품에서 「담고 다음 옷」을 누르면 구매처를 즉시 최근 태그에 기록한다. 마지막 「담고 완료」는 상세 PATCH와 owned 상태 응답을 모두 확인한 뒤에만 시트를 닫고 성공 표시한다. 저장 실패 시 시트를 유지해 재시도할 수 있다. (`frontend/src/proto/04-screens-ab.jsx` `runBulkReview`/`advance`, `frontend/src/proto/09-app.jsx` `addItemsBatch`, 2026-10-11)

구매내역 탭은 옷장 추가 시트에 있다(사진·URL 옆). 몰 칩으로 고른 뒤 「주문 내역 가져오기」로 세션을 연다.

`?orderDemo=1`의 샘플 구매내역도 결과로 바로 건너뛰지 않는다. PC에서는 추가 시트가 2열로 넓어져 왼쪽에 단계, 오른쪽에 가상 Chrome 로그인·주문내역 화면을 보여준다. 오른쪽 가상 로그인 버튼과 왼쪽 「주문내역 열기 → 옷 가져오기」를 순서대로 누르고, 수집 개수가 순차적으로 표시된 뒤 선택 목록으로 전환한다.
