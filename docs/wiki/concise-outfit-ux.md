# 코디 선택·꾸미기 UX (2026-10-25)

- `frontend/src/proto/09-app.jsx` `pickedOutfitGuide`: 중복 카테고리는 개수와 조치만 표시한다. 상품명을 붙이지 않는다. 서버 `_validate_picked_outfit`도 같은 정책을 쓴다.
- `pickedMissingCategories`와 `04-screens-ab.jsx` `runPickedCoord`: 원피스 또는 상의/아우터+하의/스커트 여부를 보고 부족한 상의·하의만 별도 목록으로 표시한다. 중복을 먼저 해결해야 외부 추천 CTA가 나온다.
- 확인 모달은 질문+한 문단 설명, 공통 `CheckField`의 외부 추천/다시 보지 않기를 사용한다. 모바일 구매내역 하단 중복 안내는 텍스트만 비우고 높이를 유지한다.
- `LiveCoordinate.external_only`: 선택한 아이템만 유지하고 부족한 상의·하의·신발을 기존 외부 제안 후보와 상품컷 생성으로 보충한다. 다른 옷장 아이템은 후보에서 제외한다. 외부 아이템을 옷장에 저장하지 않고 코디 `metadata.studio_items`에 저장하여 재조회·룩북에서도 복원한다. 나중에 AI 착장을 요청할 때에도 본인 코디의 외부 상품컷 경로를 복원한다. 실제 쇼핑몰 상품 검색이나 구매 링크 제공 기능은 아니다.
- `style/collage-canvas.jsx`: 입력된 텍스트도 요소 전체 드래그로 이동한다. 4px 이하는 탭 편집, 별도 이동 핸들은 삭제하고 장식 방향키 이동을 유지한다. 변형 핸들은 회전+크기 SVG로 표시한다.
- `02-shared.jsx` `RangeField`: %/° 출력만 정수로 절삭한다. 실제 값은 그대로 보존한다. 펜 굵기도 공통 RangeField로 통일한다.
- `.agents/skills/concise-ux-writing/SKILL.md`: UI 문구 수정 마지막 검토에 자동 적용한다. 개인 공통 스킬에도 같은 내용을 설치한다.

검증: 프런트 관련 16개, 백엔드 추천 흐름 15개 테스트 통과 및 프로덕션 빌드 성공. 격리된 실제 편집기에서 44%/2° 출력, 입력된 텍스트 본문 드래그, 펜 굵기 테두리를 확인했다. 375px/720px 프레임에서 실제 확인 모달의 문구와 체크박스를 확인했다. 로컬 로그인 API가 연결되지 않아 전체 로그인 후 흐름, 실제 외부 이미지 생성·DB 저장, 실기기 터치 검증은 수행하지 않았다.

2026-10-25 후속: 선택 조치 모달의 제목→목록 간격을 14px에서 21px(1.5배)로 늘렸다. 목록 내부 간격과 CTA 배치는 유지하고 콘텐츠 높이만 7px 늘어난다.

2026-10-25 추가: 확인 모달의 두 체크박스를 공통 CheckField compact(28px)로 연속 배치했다. 체크 자체는 상태만 바꾸고 모달을 유지한다. 만들기에서 다시 보지 않기의 true/false를 skip/show로 저장하며 취소는 저장하지 않는다.

후속 검증: 375px/720px 실제 확인 모달에서 두 행이 간격 없이 배치되고 체크 자체로 닫히지 않음을 확인했다. 실제 만들기 핸들러를 격리 실행해 true→skip, false→show 저장을 확인했다(실제 생성 요청 없음). 프런트 관련 테스트 9개 및 프로덕션 빌드 통과.
