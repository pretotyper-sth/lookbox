# 플랫레이 소품은 가방 한가운데에 같은 색으로 올리지 않는다

우하단 악세서리를 같은 좌표에 비슷한 크기로 포개면, 검정 선글라스가 검정
가방에 묻힌다. 가방이 자리를 잡고(`lookAccRank`), 소품은 더 작게 주변
후보(`LOOK_ACC_CANDIDATES`)로 간다. 가방 자리도 우하단 바깥 모서리가 아니라 안쪽
여백 안에 둔다. 구분은 자리로만 한다. 흰 발광·테두리는
선글라스처럼 이질감이 나서 그리지 않는다(2026-09-06).
개수가 다르면 덩어리 크기가 달라 3장은 작고 4장은 커 보인다. 오늘 코디는
`flattenLookBoard`가 그린 뒤 bbox를 `LOOK_PACK`(1.03)로 맞춘다. 1.03은 0.86의
1.2배, 패킹 전 4개짜리 2번 카드의 약 95%. 기하 가운데가 위로 보여
`LOOK_NUDGE_Y` 2.4%만 내린다. 전체 패킹은 원본 캔버스 여백을 포함해 기존 구조를
유지한다. 가방 등 소품은 실제 알파 실루엣을 기준 크기에 맞춰 양방향 보정한다. 작은
원본은 최대 1.25배 키우되, 큰 원본은 같은 기준 크기까지 줄여 의류만큼 커지지 않게 한다.
악세서리 후보도 모든 축에서 카드 끝보다 안쪽에 둔다. 알파 영역을 읽지 못해도
가방을 축소하지 않고, 가방은 기본 1.2배·작은 원본은 최대 1.25배까지 키운다.
플랫레이 우클릭은 합성 이미지를 실제 PNG 바이트로 변환한 뒤 클립보드에 쓴다. 표시
초기 경로도 가방 기본 1.2배를 적용하고, 변경된 합성 결과는 캐시 `|flat15`를 쓴다.
룩북 상품컷은 패킹 전 크기
(`pack={false}`, 캐시 `|flat1`)(2026-09-14).

2026-09-20: 아우터와 상의가 같은 코디에 있을 때는 고정 좌표에서 겹치지 않는다. 합성 직전
각 PNG의 실제 알파 실루엣을 읽어 독립 셀 안에 맞추므로, 투명 여백이 크거나 원본 크기가 다른
이미지도 셀 밖으로 침범하지 않는다. 상품컷은 의류 레이어 여부와 무관하게 2개는 좌우, 3개는
삼각, 4개는 2×2, 5개는 2×3 중심 정렬로 통일하고 그 이상은 균등 그리드를 쓴다. 캐시는
`flat17`이다.

근거: `frontend/src/proto/05-screens-cde.jsx` `layerSafeCells`, `lookPlacement`,
`drawLookCutout`.

의류를 가릴 일이 없다. 제안 아이템으로 가방·소품이 한 개 들어올 때도 가방 크기는
