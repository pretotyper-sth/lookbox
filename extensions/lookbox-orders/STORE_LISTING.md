## 짧은 설명

쇼핑몰 구매내역에서 고른 옷을 RealCloset 옷장에 간편하게 담습니다.

## 상세 설명

RealCloset 구매내역 확장 프로그램은 사용자가 직접 선택한 쇼핑몰의 로그인 창과 주문내역을 Chrome에서 엽니다. 로그인 후 주문내역에서 상품명, 이미지, 가격과 구매일을 읽어 RealCloset의 선택 화면에 보여주며, 사용자가 고른 상품만 옷장 등록에 사용합니다.

- 쇼핑몰 로그인 정보와 결제 정보는 읽거나 저장하지 않습니다.
- 사용자가 가져오기를 실행했을 때만 주문내역을 확인합니다.
- 선택한 상품의 정보와 이미지만 RealCloset로 전달합니다.
- 광고, 사용자 추적 또는 데이터 판매에 사용하지 않습니다.

## 단일 목적

지원하는 쇼핑몰의 주문내역에서 사용자가 선택한 의류 상품을 RealCloset 옷장에 등록합니다.

## 권한 사용 사유

- `tabs`: 사용자가 선택한 쇼핑몰의 로그인·주문내역 팝업을 열고, 로그인 완료 뒤 주문내역으로 이동하며, 작업 완료 시 해당 팝업을 닫기 위해 사용합니다.
- `scripting`: 사용자가 가져오기를 요청한 주문내역 페이지에서 상품명, 주소, 이미지, 가격과 구매일을 읽기 위해 사용합니다.
- 호스트 접근: 지원 쇼핑몰 주문내역과 사용자가 선택한 상품 이미지를 읽는 단일 기능에만 사용합니다.
